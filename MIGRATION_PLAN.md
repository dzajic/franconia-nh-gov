# Franconia website

This repository is a preview of a redesigned town website. It is not the live site. The live site remains [franconianh.gov](https://www.franconianh.gov/) until the town decides to switch.

The preview has a homepage for residents, an About page for people who live here or may move here, and the existing town pages at the same addresses. Meeting agendas and minutes can be searched. The last 12 months are listed by month. Older years stay closed until someone opens them. The document files themselves are not stored in this project.

See the README for how to preview the site, edit a page, and add a document. The alert bar and the “this week” events are samples, not confirmed notices. Anything in square brackets, such as [hours], is still unknown.

The earlier tools that copied the old website are no longer in this project. New meeting documents are added by hand, or with the importer described in the README.
