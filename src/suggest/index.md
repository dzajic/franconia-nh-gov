Anyone can suggest a fix. You do not need special software. On any page, choose Suggest a change at the bottom of the screen.

## Edit this page

You need a free GitHub account. GitHub is the website where these pages are written. It will help you sign up if you do not have an account yet.

Edit this page opens that page’s text. If the page is built from a shared list, the link opens the list. Change this page’s entry, and leave the others as they are.

Make your edit. Describe what you changed and why. Click Propose changes.

A town reviewer approves it before it appears on the site. Every change has a public history. People can see what changed, and when.

## Make a general suggestion

Choose this if you would rather describe the problem than edit the page. It opens a GitHub issue with the page’s address already filled in. A town reviewer reads the issue.

## Contact by email

This writes to the person who maintains the page. If the page belongs to a department that has an email in the departments list, that address is used. Otherwise the message goes to the town contact address in the site data. A page can also name someone directly with ownerEmail.

The subject line is “Suggestion:” plus the page title, and the message includes the page’s address. When neither the department nor the town contact address is a real email, this choice is left off the dialog.
