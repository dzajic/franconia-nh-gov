## Do I need an account?

Edit this page and Report an issue need a free GitHub account. GitHub will help you sign up. Contact us does not.

## What happens after I suggest?

Edit this page opens that page’s text. Describe the change and click Propose changes. Report an issue opens a GitHub issue with the page’s address filled in.

## Who reviews it?

A town reviewer approves an edit before it appears on the site. Every change has a public history.

## Can I just email?

Contact us is for the town’s Technology Committee. That committee is still being set up, so the button opens a short page instead of an email.
